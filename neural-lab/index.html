01 Préparer

100 à 12 000 caractères. Découpage chronologique : 70 % entraînement, 15 % validation, 15 % test réservé. Les motifs répétés rendent ce jeu facile.

L’exemple a appris le texte d’Alice. Charger ou initialiser remplace les poids courants.

Ce que ce modèle simplifie

Un token est ici un caractère, pas un morceau de mot. Le Transformer a un bloc, une tête, deux normalisations et une activation tanh. Il prédit le caractère suivant. Ce n’est ni GPT ni un modèle préentraîné.

Les dimensions et le corpus changent seulement après « Initialiser ». Cela efface l’apprentissage courant. Exportez-le pour le conserver.

02 / EXPLORER

Du texte à la prédiction

Glisser : tourner · molette : approcher · cliquer : examiner
Le panneau à droite donne les valeurs exactes.
Relecture ralentie d’un calcul réel · aucun temps matériel simulé.

Le jeu : lire un début de texte, prédire la lettre suivante, comparer à la vraie lettre, puis corriger les poids.

La perte mesure la surprise face à la bonne lettre. Plus bas est meilleur. Ce n’est pas un pourcentage d’erreur.

Les poids restent fixes. Le modèle transforme votre contexte en probabilités, puis choisit un caractère. La réponse peut être absurde : le modèle est minuscule.

Une question testable : combien de bits peut-on retirer aux poids avant de dégrader la prédiction ? Écrivez votre hypothèse avant de mesurer.

Poids arrondis puis calcul flottant : quantification simulée. Biais et gains restent flottants. Aucune accélération entière ni économie de RAM navigateur n’est annoncée.

Déboguer une idée fausse

Sans masque, une position peut lire les suivantes. Avec un seul bloc et une perte sur la dernière position, cela ne change pas forcément cette perte.

Pour une petite recherche : recommencez avec les graines 42, 43, 44 ; gardez le même corpus et les mêmes corrections ; comparez ensuite sur une cible réelle. Ici, aucun Pi ni instrument d’énergie n’est connecté.
