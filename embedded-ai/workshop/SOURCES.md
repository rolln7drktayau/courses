# Educational and technical references

Roland Cédric TAYO — 21 October 2026.

## Pedagogical choices

- [Freeman et al., PNAS 2014](https://doi.org/10.1073/pnas.1319030111): meta-analysis supporting active learning in undergraduate STEM. It does not establish the effect of this particular workshop.
- [Cornell, Designing Group Work Assignments](https://teaching.cornell.edu/resource/getting-started-designing-group-work-assignments): align goals, stages, organisation and debrief. Applied here as a bounded common case and an explicit synthesis.
- [CMU Eberly, Group Work](https://www.cmu.edu/teaching/designteach/inclusiveexcellence/groupwork/index.html): small complementary teams, rotating roles and monitored participation. Applied here as five roles, criticism and an independent check.

This is guided inquiry with peer teaching, not an unstructured request to research the Internet. All students share core calculations, then encounter the other six topics through teach-backs, notes and the exit questions. The teacher still checks reasoning and addresses misconceptions. The observation of what students can explain is more useful than counting completed text boxes.

## Technical starting points

- [SRI: Shakey](https://www.sri.com/hoi/shakey-the-robot/), [CMU: ALVINN](https://publications.ri.cmu.edu/alvinn-an-autonomous-land-vehicle-in-a-neural-network): historical needs and limits; physical autonomy does not imply all computation is on board.
- [Stanford CS231n neural-network notes](https://cs231n.github.io/neural-networks-1/): weights, activations and network structure.
- [Google ML Crash Course: splitting data](https://developers.google.com/machine-learning/crash-course/overfitting/dividing-datasets): train/validation/test separation; the temporal-window example is original.
- [MCUNetV2](https://arxiv.org/abs/2110.15352): reduce peak working memory through architecture and execution changes.
- [Jacob et al., integer quantisation](https://arxiv.org/abs/1712.05877): representations and integer inference. Storage arithmetic alone is not a deployment benchmark.
- [MLPerf Tiny paper](https://arxiv.org/abs/2106.07597), [MLCommons methodology](https://mlcommons.org/benchmarks/inference-tiny/): identifiable tasks, configurations and comparable observations.
- [GitHub Python CI guide](https://docs.github.com/en/actions/tutorials/build-and-test-code/python), [checkout](https://github.com/actions/checkout), [setup-python](https://github.com/actions/setup-python): template workflow references checked against official documentation. The supplied CI only checks evidence-file structure.
- [Raspberry Pi remote-access and file-transfer documentation](https://www.raspberrypi.com/documentation/computers/remote-access.html): optional full-day transfer; actual toolchain and hardware still have to be verified locally.

All worksheet data, diagrams and tasks are original illustrations. The toy network is independent of the Mixer assignment; no trained project weights, completed project report or board results are redistributed.
