# Build our embedded-AI course together

**Roland Cédric TAYO — INEM. Teaching language: French.**

Open [the workshop page](https://rolln7drktayau.github.io/courses/embedded-ai/workshop/) or download `workshop-materials.zip` and open `embedded-ai/workshop/index.html`. The page embeds its mission data and uses local scripts/styles; external papers need Internet. No installation or sensor is required for the 3.5-hour version.

## The activity

About 35 students form seven teams of five. Everyone tackles the common case, then one balanced mission. Each team produces a hypothesis, a test, a source, evidence, a limitation and a response to peer criticism. Seven four-minute teach-backs plus one minute of notes each build a shared view. An individual exit check prevents the activity from only assessing one spokesperson.

The half-day is 210 minutes including a ten-minute break. It replaces part of the module; the three-hour slide deck is used as a reference, not lectured in addition. The 420-minute extension adds an independently implemented toy inference and a controlled optimisation experiment. It does not promise a complete Mixer project or ready hardware in one day.

## Files

- `protocol.pdf`: five-page academic brief, schedule, expectations, full-day extension and optional assessment.
- `worksheets.pdf`: ten A4 pages: common work, seven missions, collective summary and individual check. Print only the assigned mission per group.
- `group-01.pdf` … `group-07.pdf`: one-page mission sheets.
- `individual-check.pdf`: individual 15-minute check, not submitted through the shared page.
- `data/toy-series.csv`: three independent illustrative sequences for windowing; not the TD dataset.
- `data/experiment-template.csv`: blank observation table.
- `repository-template.zip`: blank student repository with evidence-format CI and instructions to write meaningful numerical tests. No solved model is included.
- `index.html`, `workshop.css`, `workshop.js`: browser activity and manual class-course assembler.

## Save and assemble

The notebook stores a local draft per group when the browser allows local storage. Export JSON before changing computers. There is no shared backend, account system or automatic multi-user sync. Exchange files through the agreed repository or channel.

Import at most seven files at a time under the same session name. New imports of a group replace that group's contribution in the current assembly. The assembler reports topic coverage and allows HTML/Markdown export and print-to-PDF. Importing a file does not validate its contents. The assembled course is a working document to review in class; the app does not impersonate teacher approval. Class imports are in memory only; export the assembled course before leaving.
