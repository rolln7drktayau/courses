Comment un son devient-il une liste de nombres ?

Le programme ne reçoit pas le mot : il reçoit des mesures.

  1. 01

    Échantillonner signifie mesurer un signal à intervalles réguliers. La fréquence d’échantillonnage indique le nombre de mesures par seconde.

  2. 02

    Hertz, abrégé Hz, signifie « par seconde ». À 16 000 Hz, une seconde contient 16 000 échantillons.

  3. 03

    Un bit peut valoir 0 ou 1. Un octet contient 8 bits. À 16 bits par échantillon, une seconde mono occupe 32 000 octets non compressés.

  4. 04

    Mono signifie un canal. Ce calcul exclut l’en-tête du fichier et les tampons supplémentaires.

Une image pour comprendre

Comme prendre des photos très rapprochées d’un mouvement, on mesure régulièrement une évolution.

La limite à garder en tête

Le dessin du son ne montre pas toutes les mesures ; la fréquence de dessin n’est pas celle de l’acquisition.

Aller plus loin, sans sauter d’étape

Calcul exact de cet exemple : 16 000 × 16 / 8 = 32 000 octets. Une compression peut réduire un fichier, sans changer automatiquement la taille des données une fois décodées.

Un neurone : multiplier, additionner, transformer

Commençons avec seulement deux nombres. Il n’y a pas de magie cachée.

  1. 01

    x₁ et x₂ sont les deux entrées : les indices ₁ et ₂ disent « première » et « deuxième ». w₁ et w₂ sont les poids, qui règlent leur influence.

  2. 02

    b est le biais, un décalage ajouté à la somme. Le score est z = w₁×x₁ + w₂×x₂ + b. Le signe × demande une multiplication.

  3. 03

    Avec x₁ = 1, x₂ = 0, w₁ = 0,2, w₂ = −0,1 et b = −0,5, le score vaut −0,3. Un nombre négatif se trouve sous zéro, comme une température de −3 degrés.

  4. 04

    Une fonction de sortie transforme ensuite ce score. Un seuil à zéro donnerait ici la classe 0.

Manipuler le neurone

Poids fixes : 0,2 et −0,1 ; biais : −0,5. Les curseurs changent les entrées, pas les poids.

Une image pour comprendre

Une balance additionne des contributions positives et négatives avant de basculer.

La limite à garder en tête

Ce neurone mathématique simplifie fortement un neurone biologique ; il n’en est pas une reproduction.

Aller plus loin, sans sauter d’étape

L’indice ₁ signifie « première entrée », pas une puissance. Le symbole × signifie multiplier. Vous pouvez modifier les deux entrées dans le calcul interactif.

Pourquoi ajouter une transformation ?

Sans transformation supplémentaire, empiler des calculs linéaires ne permet pas de séparer tous les groupes d’exemples.

  1. 01

    Une activation est une fonction appliquée à une valeur calculée dans le réseau.

  2. 02

    ReLU garde le plus grand entre 0 et le score z : c’est le sens de max(0, z). Exemples : −1 devient 0 ; 0 reste 0 ; +1 reste +1.

  3. 03

    La non-linéarité signifie que la transformation ne se réduit pas à une simple droite. Elle permet d’exprimer des relations plus variées.

  4. 04

    Les transformations sont choisies pour ce qu’elles permettent au modèle d’exprimer et pour leur facilité à être calculées et apprises.

Une image pour comprendre

Un clapet bloque un sens de passage et laisse passer l’autre.

La limite à garder en tête

ReLU ne représente pas une décision consciente. Une activation positive ne signifie pas « vrai ».

Aller plus loin, sans sauter d’étape

Une alternative, tanh, comprime les valeurs entre −1 et 1. Une sigmoïde donne une valeur entre 0 et 1. Ce sont des formes différentes, avec des propriétés d’apprentissage différentes.

Une couche, puis plusieurs couches

Plusieurs neurones calculent des sorties différentes à partir d’une même entrée.

  1. 01

    Une couche regroupe des opérations d’une étape. Une couche cachée est située entre l’entrée et la sortie.

  2. 02

    Un réseau est une composition de couches : la sortie d’une étape devient l’entrée d’une autre.

  3. 03

    Une activation désigne aussi le nombre intermédiaire produit. Ces nombres occupent de la mémoire pendant le calcul.

  4. 04

    Un MLP, ou perceptron multicouche, relie des couches denses : chaque sortie utilise toutes les entrées de la couche précédente.

Une image pour comprendre

Une chaîne d’ateliers transforme progressivement une matière, sans que chaque atelier voie le produit final.

La limite à garder en tête

Les couches n’apprennent pas nécessairement des concepts humains nommables. Ce dessin décrit des dépendances de calcul.

Pour une couche dense de n entrées et m sorties : n × m poids et m biais. Chaque symbole représente un nombre entier positif : n compte les entrées, m les sorties.

Une matrice évite de redessiner tous les neurones

Une matrice est simplement un tableau de nombres organisé en lignes et colonnes.

  1. 01

    On range les poids d’une couche dans une matrice W. Une ligne contient les poids d’une sortie.

  2. 02

    Le vecteur x est une liste de nombres, les entrées. Le vecteur b contient les biais.

  3. 03

    Le calcul y = Wx + b signifie : pour chaque sortie, multiplier ses poids par les entrées puis additionner et ajouter son biais.

  4. 04

    Un MAC est une multiplication suivie d’une accumulation, c’est-à-dire l’ajout à une somme. Une couche dense n → m utilise n × m MAC.

Comment dire au modèle qu’il se trompe ?

Il faut transformer un écart en un nombre à réduire.

  1. 01

    La prédiction est notée ŷ, « y chapeau ». La valeur de référence est y.

  2. 02

    Une perte mesure un écart. Exemple : L = ½(ŷ − y)². Le carré signifie multiplier l’écart par lui-même ; ½ signifie diviser par deux. L est la perte.

  3. 03

    Pour cet exemple, ŷ = 0,2 et y = 1 donnent L = 0,32. Ce choix de perte sert à comprendre le calcul.

  4. 04

    Le taux d’erreur compte les mauvaises décisions parmi les essais. Il est différent de la perte.

La limite à garder en tête

Pour une classification, on utilise souvent une autre perte, l’entropie croisée. Une perte qui baisse ne garantit pas que chaque indicateur s’améliore.

Aller plus loin, sans sauter d’étape

Le facteur ½ simplifie la dérivée. Sur N exemples, une perte moyenne additionne les pertes puis divise par N ; N est le nombre d’exemples.

Corriger un poids, pas au hasard

Le gradient indique comment la perte varie quand on change un paramètre.

  1. 01

    Dans notre petit modèle linéaire, ŷ = wx + b. Prenons x = 1, y = 1, w = 0,2 et b = 0.

  2. 02

    Si w passe de 0,20 à 0,21 en gardant b = 0, la sortie passe à 0,21 et la perte de 0,32 à 0,31205. Ici, augmenter ce poids un peu diminue la perte.

  3. 03

    Le gradient chiffre ce sens et cette sensibilité locale. Ici il vaut −0,8 pour w et b. Avec un pas η = 0,1 : w ← w − η×(−0,8). Le signe ← signifie « remplacer par le nouveau résultat ».

  4. 04

    Avec η = 0,1, w devient 0,28 et b devient 0,08. La nouvelle sortie vaut 0,36 et la perte 0,2048.

Une vraie correction, calculée ici

Modèle ŷ = wx + b ; x = 1 et référence y = 1.

Une image pour comprendre

Une pente aide à choisir un petit pas vers le bas, sans donner à elle seule le chemin entier.

La limite à garder en tête

Un pas trop grand peut augmenter la perte. Ici, la baisse est calculée pour cet exemple précis, pas garantie pour tout entraînement.

Aller plus loin, sans sauter d’étape

Pourquoi le gradient vaut-il −0,8 ? Pour L = ½(ŷ−y)², la pente par rapport à ŷ est ŷ−y = −0,8. Le symbole Δ signifie « petit changement ». Changer w de Δw change ŷ de x×Δw ; on multiplie donc la pente par x. Ici x = 1. Changer b de Δb change ŷ de Δb. Les deux gradients valent donc −0,8. On calcule tous les gradients avant de modifier les paramètres. Dans un grand réseau, cette transmission des pentes est la rétropropagation.

L’entraînement répète ce petit cycle

Un seul exemple ne suffit généralement pas.

  1. 01

    Initialiser : choisir les premiers paramètres, souvent avec des nombres pseudo-aléatoires.

  2. 02

    Prédire, calculer la perte, calculer les gradients, puis corriger les paramètres. Une mise à jour est une correction.

  3. 03

    Une époque est un passage sur l’ensemble d’entraînement. Un lot est un petit groupe d’exemples traité avant une correction.

  4. 04

    Une graine fixe le départ d’un générateur pseudo-aléatoire. Elle aide à reproduire un essai, sans garantir l’égalité bit à bit entre tous les matériels.

Aller plus loin, sans sauter d’étape

Pendant l’entraînement, il faut aussi mémoriser des valeurs utiles au calcul des gradients. Il peut donc demander bien plus de mémoire que la seule inférence. Une perte d’entraînement basse n’est pas un certificat de réussite en usage réel.

Quantifier : une règle avec moins de graduations

On représente les poids avec un nombre plus petit de valeurs possibles.

  1. 01

    Dans un exemple symétrique signé, q est un entier entre −Q et Q. s est l’échelle qui relie l’entier au nombre réel.

  2. 02

    La recette est q = borner(arrondir(w/s), −Q, Q), puis poids reconstruit ŵ = s×q. w désigne le poids initial.

  3. 03

    b est le nombre de bits. Pour notre convention : à 4 bits, Q = 2×2×2 − 1 = 7. Plus généralement, Q = 2^(b−1) − 1 ; la puissance compte les multiplications par 2. À 2 bits, on garde −1, 0, +1.

  4. 04

    Une échelle globale sert à tout le groupe ; des échelles par couche ou canal s’adaptent à plusieurs groupes, avec un coût supplémentaire.

Voir ce que l’arrondi change

Poids fixés pour l’exemple : [−1, −0,3, 0,1, 0,7]. Erreur : moyenne des écarts absolus. Quantification simulée, aucun benchmark matériel.

Une image pour comprendre

Aller plus loin, sans sauter d’étape

Borner signifie ramener une valeur trop grande à la limite. Si tous les poids d’un groupe sont nuls, on choisit par convention s = 1 pour éviter une division par zéro.

Pouvez-vous conseiller Mila maintenant ?

La lampe doit fonctionner sans réseau et ne pas envoyer les voix.

  1. 01

    Choisir une petite classification locale plutôt qu’un assistant généraliste si quelques commandes suffisent.

  2. 02

    Garder des voix indépendantes pour tester et vérifier les mots proches, bruits et silences.

  3. 03

    Préparer un budget paramètres + activations + programme, puis mesurer le délai de bout en bout sur la cible.

  4. 04

    Si la qualité devient insuffisante après compression, garder le résultat et revoir le compromis plutôt que cacher l’échec.

CHAPITRE 8 · Apprendre à chercher · REPÈRE 55

De la compréhension à l’autonomie

Une étape est acquise quand vous pouvez la montrer, pas seulement la reconnaître.

  1. 01

    Débutant : expliquer avec vos mots données, modèle, apprentissage et inférence ; refaire le calcul d’un neurone.

  2. 02

    Pratiquant : construire une chaîne simple, contrôler les données et comparer ses sorties entre PC et carte.

  3. 03

    Ingénieur : justifier les contraintes, les tests, le compromis et la maintenance avec des preuves reproductibles.

  4. 04

    Apprenti chercheur : formuler une question nouvelle et étroite, lire l’existant, tester puis expliquer ce que le résultat permet et ne permet pas de conclure.

La limite à garder en tête

Ce support ne délivre pas une expertise par simple lecture. Il vous donne la carte, les premiers outils et les critères pour progresser.

Aller plus loin, sans sauter d’étape

Défi final : dessiner votre propre objet IA en cinq blocs. Pour chaque bloc, préciser une entrée, une sortie, un coût et un risque. Entourer la première chose à mesurer. Puis expliquer votre dessin à une personne qui ne connaît pas l’IA.

RESSOURCE · LES MOTS UTILES

Le petit dictionnaire

Revenez ici dès qu’un mot vous arrête.

Activation
Fonction appliquée dans un réseau, ou résultat intermédiaire de son calcul selon le contexte.
Apprentissage
Procédure qui ajuste les paramètres d’un modèle à partir d’un objectif et de données.
Architecture
Organisation des opérations et couches d’un modèle.
Biais
Paramètre ajouté à une somme pondérée ; à distinguer d’un biais des données.
Biais des données
Déséquilibre ou particularité systématique qui peut fausser la représentation du besoin.
Bit / octet
Un bit prend deux valeurs ; un octet contient huit bits.
Calibration
Choix de réglages à partir d’exemples représentatifs ; préciser le contexte, notamment la quantification.
Capteur / actionneur
Le capteur observe un phénomène ; l’actionneur produit un effet physique.
Classification
Attribution d’une catégorie à une entrée.
Convolution
Application répétée d’un filtre partagé sur des voisinages de données.
CPU / GPU / NPU
Processeur généraliste / processeur parallèle / accélérateur spécialisé pour certaines opérations IA.
Énergie / puissance
Quantité consommée en joules / rythme de consommation en watts.
Époque / mise à jour
Passage sur l’entraînement / correction des paramètres.
Float32 / Int8
Formats numériques utilisant respectivement 32 bits flottants et 8 bits entiers.
Flottant
Représentation de nombres avec une précision limitée, permettant des valeurs petites ou grandes ; certains calculs sont arrondis.
Volatile
Se dit ici d’une mémoire qui perd son contenu quand son alimentation est coupée.
Généralisation
Réussite sur des données nouvelles pertinentes pour le besoin.
Gradient
Ensemble de variations locales de la perte par rapport aux paramètres.
Inférence
Utilisation d’un modèle pour calculer une sortie ; les poids restent généralement fixes.
Latence / débit
Délai d’une réponse / quantité de réponses par unité de temps.
Mémoire Flash / RAM
Mémoire non volatile / mémoire de travail généralement volatile.
Modèle / paramètres
Fonction réglable / nombres qui règlent cette fonction.
Normalisation
Transformation selon une règle d’échelle explicite ; plusieurs méthodes existent.
Perte / taux d’erreur
Écart numérique optimisé / proportion de mauvaises décisions.
Quantification
Représentation d’un ensemble de valeurs par un ensemble plus limité de niveaux.
Runtime / backend
Logiciel d’exécution / chemin choisi pour réaliser ses calculs sur un matériel.
Temps réel
Respect d’exigences temporelles définies ; pas seulement un calcul rapide.
Token / embedding
Unité discrète d’une suite / liste de nombres apprise associée à cette unité.
Validation / test
Données pour choisir les réglages / données réservées à l’évaluation finale.
